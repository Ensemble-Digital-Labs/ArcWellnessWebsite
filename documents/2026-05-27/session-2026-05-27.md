- **`ArcScrollShell`**: on mobile/touch, skips Locomotive + scroll lock; uses normal document scroll with `#main` wrapper + `touch-pan-y`; dispatches `arc-locomotive-ready` so GSAP pins still init.
- Updated all GSAP sections that used `scroller: #main` to use shared helpers (hero, concerns, welcome, founder, pins, scroll reveal, micro/chapter if used).
- **`ArcSiteHeader`**: menu open locks `document.body` overflow on native scroll path.
- **`globals.css`**: touch pan CSS for `#main.touch-pan-y`.
