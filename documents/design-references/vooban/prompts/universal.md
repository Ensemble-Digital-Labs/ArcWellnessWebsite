# Design System: Vooban (https://vooban.com/)

Use these values exactly when building UI. Do not substitute or "improve" any color, size, or spacing.

## Colors

- **Primary:** `#1458e4`  main CTAs, focused state, primary buttons
- **Accent:** `#5dceff`  highlights, badges, secondary CTAs
- **Ink:** `#232020`  body text
- **Canvas:** `#ffffff`  page background
- **Canvas Alt:** `#ededed`  section / card background

## Typography

Families: `NB International`, `NB International Mono`

- **Display XXL:** `NB International` · 58px / weight 400 / lh 1.00 / ls -1.74px
- **Display XL:** `NB International` · 44px / weight 400 / lh 1.09 / ls -1.32px
- **Heading LG:** `NB International` · 26px / weight 400 / lh 1.31 / ls -0.78px
- **Heading MD:** `NB International` · 20px / weight 400 / lh 1.40 / ls -0.2px
- **Body MD:** `NB International` · 16px / weight 400 / lh 1.38
- **Body SM:** `NB International` · 14px / weight 400 / lh 1.43
- **Caption:** `NB International` · 12px / weight 400 / lh 1.42
- **Overline:** `NB International Mono` · 11px / weight 400 / lh 1.36

## Spacing

Base unit **2px**. Scale: 2px, 4px, 6px, 8px, 10px, 12px, 16px, 20px, 24px, 30px, 32px, 40px, 48px, 56px. Max content width: `1016px`.

Section spacing (between major page regions): 48px, 56px, 80px, 84px, 96px, 100px, 104px, 106px, 128px, 160px, 244px, 317px, 1440px, 1800px.

## Border radius

- `4px` (used 128×)  a, button, div
