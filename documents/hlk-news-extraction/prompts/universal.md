# Design System: Hlkagency (https://hlkagency.com)

Use these values exactly when building UI. Do not substitute or "improve" any color, size, or spacing.

## Colors

- **Primary:** `#ed4830`  main CTAs, focused state, primary buttons
- **Ink:** `#051c2c`  body text
- **Canvas:** `#ffffff`  page background
- **Muted:** `#666666`  secondary text, placeholders, captions
- **Hairline:** `#cfcfcf`  borders, dividers

## Typography

Families: `Pathway Extreme`

- **Display XXL:** `Pathway Extreme` · 58px / weight 100 / lh 1.79
- **Heading LG:** `Pathway Extreme` · 22px / weight 800 / lh 1.41
- **Body LG:** `Pathway Extreme` · 18px / weight 300 / lh 1.78

## Spacing

Base unit **4px**. Scale: 12px, 20px, 48px, 60px, 68px, 100px, 120px. Max content width: `1700px`.

Section spacing (between major page regions): 48px, 50px, 60px, 67px, 68px, 70px, 85px, 100px, 120px, 170px, 195px, 196px, 420px.

## Border radius

- `50%` (used 288×)  div
