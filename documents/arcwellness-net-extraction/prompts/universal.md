# Design System: Arcwellness (https://www.arcwellness.net/)

Use these values exactly when building UI. Do not substitute or "improve" any color, size, or spacing.

## Colors

- **Ink:** `#000000`  body text
- **Canvas:** `#ffffff`  page background
- **Canvas Alt:** `#d9d9d9`  section / card background
- **Hairline:** `#e5e5e5`  borders, dividers

## Typography

Families: `Montserrat`

- **Display XL:** `Montserrat` · 47px / weight 700 / lh 1.11 / ls -0.94208px
- **Display LG:** `Montserrat` · 37px / weight 500 / lh 1.14 / ls -0.73472px
- **Heading LG:** `Montserrat` · 26px / weight 500 / lh 1.19 / ls -0.52736px
- **Body LG:** `Montserrat` · 26px / weight 500 / lh 1.23 / ls -0.52736px
- **Body MD:** `Montserrat` · 16px / weight 400 / lh 1.50
- **Body SM:** `Montserrat` · 14px / weight 400 / lh 1.50
- **Button:** `Montserrat` · 16px / weight 700 / lh 1.50

## Spacing

Base unit **4px**. Scale: 4px, 8px, 12px, 16px, 20px, 24px, 28px, 32px, 40px, 48px, 80px, 108px. Max content width: `1398px`.

Section spacing (between major page regions): 48px, 49px, 58px, 86px, 95px, 106px, 108px, 174px.

## Border radius

- `50%` (used 92×)  a
- `300px` (used 68×)  a
- `15px` (used 66×)  li, div
