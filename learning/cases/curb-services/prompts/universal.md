# Design System: Curbcph (https://curbcph.tv)

Use these values exactly when building UI. Do not substitute or "improve" any color, size, or spacing.

## Colors

- **Primary:** `#0000ee`  main CTAs, focused state, primary buttons
- **Ink:** `#201f1f`  body text
- **Canvas:** `#f7f3f1`  page background
- **Muted:** `#424242`  secondary text, placeholders, captions
- **Hairline:** `#c5c5c5`  borders, dividers
- **On Primary:** `#ffffff`  text/icon on primary backgrounds

## Typography

Families: `Oldschool Grotesk Condensed`, `Items Condensed`, `Neue Haas Grotesk Display Pro`

- **Display XXL:** `Oldschool Grotesk Condensed` · 86px / weight 700 / lh 0.85 / ls -0.32px
- **Display XL:** `Items Condensed` · 46px / weight 400 / lh 0.78 / ls -0.9216px
- **Body MD:** `Neue Haas Grotesk Display Pro` · 15px / weight 600 / lh 1.00 / ls -0.32px
- **Overline:** `Oldschool Grotesk Condensed` · 16px / weight 700 / lh 1.00 / ls -0.32px

## Spacing

Base unit **4px**. Scale: 4px, 8px, 12px, 16px, 24px, 32px, 48px, 56px, 64px, 96px, 112px. Max content width: `379px`.

Section spacing (between major page regions): 48px, 64px, 112px.

## Border radius

- `6px` (used 31×)  div
